#GENESIS – Hackathon Website

A responsive and user-friendly website developed for **GENESIS**, a 24-hour national hackathon organized by the **Rotaract Club of SRM Easwari Engineering College**.

The website serves as a centralized platform where participants can explore everything they need to know about the event—from registration and schedules to prizes, FAQs, and contact information. It was designed to provide a seamless experience and help participants understand the hackathon before and during the event.

## 🌟 Features

* 📝 Registration and event details
* 🏆 Prize pool information
* 📅 Event schedule and timeline
* ❓ Frequently Asked Questions (FAQ)
* 📍 Venue and contact details
* 📱 Responsive design for desktop and mobile devices
* 🎨 Clean and intuitive user interface

## 🛠️ Tech Stack

* **Frontend:** React
* **Build Tool:** Vite
* **Styling:** CSS
* **Version Control:** Git & GitHub
* **Deployment:** Vercel

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Roshinivb/genesis-hackathon.git
```

### Navigate to the project

```bash
cd genesis-hackathon
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
